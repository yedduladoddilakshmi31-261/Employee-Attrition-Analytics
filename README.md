# Employee Attrition Analytics

## Project Overview

Employee Attrition Analytics is a data analysis project that studies employee attrition using HR data. The project identifies patterns related to employee turnover and explores factors such as department, overtime, job satisfaction, job role, income, age, and work-life balance.

## Dataset

The dataset contains employee information including:

- Age
- Department
- Job Role
- Monthly Income
- Job Satisfaction
- Overtime
- Work-Life Balance
- Years at Company
- Distance From Home
- Attrition

Dataset file:
`WA_Fn-UseC_-HR-Employee-Attrition.csv`

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Analysis

The project includes:

- Data loading and exploration
- Missing value checking
- Employee attrition analysis
- Department-wise attrition
- Overtime-wise attrition
- Job satisfaction analysis
- Job role analysis
- Monthly income analysis
- Years at company analysis
- Distance from home analysis
- Business travel analysis
- Work-life balance analysis
- Age group analysis

## Key Objective

The main objective is to understand employee attrition patterns and identify factors associated with employees leaving the organization.
